
# 커서 페이지네이션 가이드

## 1. 개념

커서 페이지네이션은 이전 조회 결과의 마지막 데이터를 기준으로
다음 데이터를 조회하는 방식이다.

## 2. 응답 구조

- content: 현재 페이지의 데이터 목록
- nextCursor: 다음 요청에서 사용할 기준값
- hasNext: 다음 페이지 존재 여부

## 3. 사용 원칙

1. 커서는 정렬 기준과 일치해야 한다.
2. 정렬 기준은 가능한 한 중복되지 않도록 구성한다.
3. 다음 데이터가 있는지 확인하기 위해 페이지 크기보다
   하나 더 조회하는 방식을 사용할 수 있다.
4. 추가 데이터가 없으면 hasNext를 false로 반환한다.
5. 다음 페이지가 없다면 nextCursor는 null로 반환한다.

## 4. 주의사항

CursorPage는 공통 응답 구조만 담당한다.
실제 커서 계산, 정렬, DB 조회는 각 도메인의 서비스와
리포지토리에서 처리해야 한다.
